# 🚀 Personal Developer Portfolio | FDA Web Engineering Capstone

A production-grade, fully responsive, dark-mode & glassmorphism-themed personal developer portfolio built as the final Capstone project for the **Faran Digital Academy (FDA) Web Engineering Internship (Cohort 2026)**.

---

## 🛠️ Tech Stack & Architecture

* **Framework:** Next.js 15 (App Router & Component Architecture)
* **Styling:** Tailwind CSS (Custom Dark Blue Glassmorphism Theme)
* **Animations:** Framer Motion (Smooth Staggered Animations & Micro-Interactions)
* **Deployment:** Vercel (Optimized for 100 Performance Score)

---

## ✨ Features

* **Glassmorphism UI:** Modern dark-blue translucent design with custom background glow accents and high contrast text readability.
* **Component-Based Structure:** Clean modular architecture (`Navbar`, `Hero`, `About`, `Skills`, `Workflow`, `Projects`, `Testimonials`, `Contact`, `Footer`).
* **Interactive Contact Form:** Built-in form handling for direct communication.
* **Theme Toggle:** Dynamic Dark and Light mode switcher with smooth transitions.
* **FDA Internship Showcase:** Comprehensive breakdown of all internship deliverables, live demos, and source code repository links.
